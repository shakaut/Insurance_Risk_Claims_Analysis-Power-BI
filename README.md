# Insurance Policies & Claims Analysis Dashboard

An interactive Power BI dashboard for analyzing insurance policies, customer profiles, vehicle details, and claim behavior to support risk analysis and business decisions.

## Dashboard Video Preview 
https://drive.google.com/file/d/1xJGYD9E6vlWkCvsIgN2TVSYHuww3kFAu/view?usp=sharing


## Project Overview

This practice project helps analyze:

- Insurance performance
- Claim trends
- Customer demographics
- Vehicle risk patterns
- High-risk segments

## Dataset Includes

- Customer demographics (Age, Gender, Education, Income, Marital Status)
- Vehicle details (Car Make, Car Year, Car Use, Coverage Zone)
- Claims data (Claim Amount, Claim Frequency)
- Driving behavior (Kids Driving)

## KPIs

- Total Policies
- Total Claim Amount
- Claim Frequency
- Average Claim Amount
- Gender-wise Policies

## Visualizations

- Policies & Claims by Car Use
- Policies & Claims by Car Make
- Coverage Zone Analysis
- Age Group Claim Trends
- Car Year Impact Analysis
- Kids Driving vs Claims
- Education Analysis
- Education & Marital Status Matrix

## Key Features

- Interactive dashboard
- Dynamic DAX measures
- KPI-based reporting
- Risk & claims analysis
- Clean UI design

## Tools Used

- Power BI
- DAX
- Data Visualization

## What I Learned

- Insurance analytics
- KPI dashboard development
